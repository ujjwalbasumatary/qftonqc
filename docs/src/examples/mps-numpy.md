# Python tutorial

The [Python tutorial](https://ujjwalbasumatary.github.io/qftonqc/python/)
accompanies the quantum-computing and MPS chapters of the book. It contains
the Qiskit course demonstrations and the NumPy implementations of MPS
algorithms, with a reading order, explanations, saved outputs and exercises.

The Qiskit demonstrations develop gates and measurements, spin dynamics,
the quantum Fourier transform, phase estimation, state preparation and
oscillator spectra. The NumPy walkthroughs work through Schmidt truncation,
canonical forms, MPO contractions, DMRG, TEBD, TDVP and VUMPS. Tensor diagrams
show the contractions used in the MPS code.

Read the demonstrations on the Python site, or download the notebooks to
run them in JupyterLab. The tutorial explains the environments needed for the
Qiskit and NumPy examples. Both are independent of the Julia simulation
environment.

The [Julia worked examples](index.md) use MPSKit for the Ising, Schwinger and
field-theory calculations described here. The
[course material](../course.md) also lists the earlier classroom notebooks
and student projects.
